# Phase 3 Plan — Location System

**Goal:** Replace browser geolocation API with a manual location selection system. Users can search cities from a bundled database, enter lat/lon coordinates directly, save multiple locations, and switch between them. One location is active at a time for clock display. Location persistence across sessions.

---

## Must Haves

- City search with fuzzy matching against bundled city database (~5,000–10,000 major cities)
- Manual lat/lon input with validation
- "Detect location" button using browser geolocation API with robust timeout handling
- Location persistence via localStorage (saved locations + active location)
- Multi-location support — save multiple locations, one active at a time
- First-run flow: attempt auto-detect, fall back to search prompt gracefully
- Location change triggers clock update with new lat/lon
- All existing tests remain green
