# Plan 04: Full Verification and Manual User-Journey Sign-Off

## Objective
<objective>
Run the focused integration tests and the full regression suite, then perform the Phase 14 manual user journey so the inline selector UI is verified not just as code but as the intended product experience: discoverable on hover/tap, immediately reactive, and persistent across refresh without regressions in the rest of the app.
</objective>

<task id="14-04-02" type="manual-test">
<title>Perform the full Phase 14 manual user journey</title>
<read_first>
- .planning/ROADMAP.md — Phase 14 success criteria lines 178-187
- .planning/phases/14-format-selector-ui-integration/14-CONTEXT.md — D-26 manual test flow
- .planning/phases/14-format-selector-ui-integration/14-UI-SPEC.md — interaction and responsive contract
</read_first>
<action>
Run `npm start` and verify this exact manual sequence in a browser:

1. Load page and confirm four visible clock segments are present for Year, Date, Standard Time, and Solar Time.
2. Hover each segment on desktop and confirm:
   - only the active segment shows the border
   - the correct label appears below it
   - the rest of the clock stays visually minimal
3. Click each segment and confirm:
   - a dropdown opens anchored to that segment
   - only one dropdown is open at a time
   - dropdown options match the registered formats for that component
4. Choose a different format in each component and confirm:
   - the display updates immediately without reload
   - the dropdown closes immediately after selection
5. Refresh the page and confirm all chosen formats persist.
6. Switch Standard Time between `24h`, `Decimal`, and `Longitudinal` and confirm the display continues live-updating after each change.
7. Simulate mobile or test on a touch device and confirm tap opens dropdowns directly without requiring hover.

Record any deviation before marking the phase complete.
</action>
<acceptance_criteria>
- All four components are independently interactive in the browser
- Hover/focus treatment appears only on the active component
- Each component dropdown shows the correct option set
- Selection updates the display immediately without reload
- Refresh preserves the chosen formats
- Mobile or simulated touch opens dropdowns directly
- No regression is observed in location, sky background, moon indicator, or alarm behavior during the session
</acceptance_criteria>
</task>
